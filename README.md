# Pearlenergy Astro Starter

A minimal Astro website with a sample homepage.

## Requirements

- Node.js `22.23.4` or newer
- npm (included with Node.js)
- Visual Studio Code (recommended)

On macOS, install the current compatible Node.js LTS release and Visual Studio Code, then open this folder in VS Code. The workspace recommends the official Astro extension, `astro-build.astro-vscode`.

## Run locally

Install the project dependencies and start Astro's development server:

```sh
npm install
npm run dev
```

Open the local URL printed by Astro (usually <http://localhost:4321>). Edit `src/pages/index.astro`; the development server refreshes the page when you save.

## Production build

```sh
npm run build
```

Astro writes the production site to `dist/`. To preview that build locally, run `npm run preview`.

Astro is installed as a project dependency. There is no need to install its CLI globally.
